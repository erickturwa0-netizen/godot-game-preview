# Fruitblade (Godot Web)

Godot HTML5 export of Fruitblade.

## Play

After uploading `index.wasm` and `index.pck` to this repo (or enabling GitHub Pages), open the Pages URL or serve the files locally.

## Files needed
- index.html
- index.js
- index.wasm (~39MB)
- index.pck (~6.8MB)
- index.audio.worklet.js
- index.audio.position.worklet.js

Large binaries must be added manually (GitHub web upload or git LFS) because of size limits.
