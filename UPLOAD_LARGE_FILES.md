# Upload these large files manually

GitHub web upload supports up to 100MB per file.

Go to the repository → Add file → Upload files, then upload:

1. **index.js** (from the original zip)
2. **index.wasm** (~39 MB)
3. **index.pck** (~6.8 MB)

After uploading, enable **GitHub Pages**:
- Settings → Pages → Source: Deploy from a branch → main / root

Then the game will be live at:
`https://erickturwa0-netizen.github.io/godot-game-preview/`

The original zip is here: https://files.catbox.moe/ouaa2p.zip
